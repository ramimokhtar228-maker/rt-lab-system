# RT LAB — معامل رامي مختار
نظام إدارة معمل تحاليل (PWA)

## التشغيل
1. ارفع كل محتويات المجلد معاً على الاستضافة (GitHub Pages / أي سيرفر)
2. افتح الرابط https://...
3. للتثبيت كتطبيق: Chrome/Edge → تثبيت التطبيق

## محلياً
```bash
python3 -m http.server 8080
```

## ملاحظات
- البيانات تُحفظ محلياً في المتصفح (localStorage)
- امسح الكاش بعد كل تحديث (Ctrl+F5)

## تعديلات نسخة الإصلاح (v8)
- الحذف: أي طلب / تحليل / مورد / موظف بتحذفه بيتسجّل في سجل محذوفات (DB.deleted) ومش بيرجع من السحابة أو من جهاز تاني
- فتح البرنامج: seedTests و applyCatalogPrices بقوا يشتغلوا تلقائياً مرة واحدة لكل نسخة كتالوج (كانوا بيرجّعوا التحاليل المحذوفة ويمسحوا تعديلاتك في كل فتح)
- التحليل اللي بتعدّله بإيدك بيتعلّم manual ومش بيتكتب عليه تلقائياً
- صور الروشتة بتتصغّر (1400px / جودة 0.7) قبل الحفظ + تصغير الصور الكبيرة القديمة تلقائياً
- المزامنة: أي حفظ بيحصل أثناء مزامنة شغالة بيتدفع بعدها بدل ما يتجاهل
- تفعيل navigator.storage.persist() عشان المتصفح ميمسحش البيانات
- ملاحظة: الحذف القديم (قبل هذا التحديث) مالوش سجل — لو رجع عنصر مرة، احذفه مرة كمان وهيتسجّل
